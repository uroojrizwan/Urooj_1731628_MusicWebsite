## Description

Melovia is a music streaming website designed for users to explore and listen to songs from different artists.

The website provides a simple and attractive interface with a responsive design. Users can explore albums, view featured artists, play songs using the music player, and contact through the contact form.

* Responsive Navigation Bar

* Music/Album Section
* Featured Artist Section
* Interactive Music Player
* Play and Pause Controls
* Next Song Control
* Like Button
* Volume Control
* Contact Form
* Form Validation
* Footer with Social Links
* Responsive Design


## Form Validation

The contact form includes validation to make sure the user enters correct information.

### Name Validation

* Name is required.
* Name must contain at least 3 letters.
* Numbers are not accepted as a name.

### Email Validation

* Email is required.
* At least 3 characters are required before the `@` symbol.
* Numbers are allowed before `@`.
* A valid email format is required.

### Valid Email Examples

* [example@gmail.com](mailto:example@gmail.com)
* [abc123@gmail.com](mailto:abc123@gmail.com)
* [student01@yahoo.com](mailto:student01@yahoo.com)

### Invalid Email Examples

* [ab@gmail.com](mailto:ab@gmail.com)
* abc@
* @gmail.com
* abc gmail.com

The form does not submit when the entered information is invalid.


## Website Sections

### 1. Home

The Home section contains the main hero area with a welcome message and introduction to Melovia.

### 2. About

The About section provides information about the Melovia website.

### 3. Music

The Music section contains album cards featuring different songs and artists.

### 4. Artists

The Artists section displays a featured artist with an image and information.

### 5. Music Player

The music player allows users to interact with songs.

It includes:

* Play/Pause
* Next Song
* Like
* Volume Control

### 6. Contact

The Contact section contains a form where users can enter their information. Form validation is applied to the input fields.
